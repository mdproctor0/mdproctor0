## About Me

I design, secure, and operate cloud infrastructure in Azure. My work sits at the intersection of cloud engineering and security — building environments that are architected correctly from the start rather than secured after the fact.

I specialize in identity architecture, network segmentation, infrastructure as code, and cloud monitoring. On the security side I've built threat hunting playbooks, automated STIG remediation at scale, and operationalized vulnerability management workflows.
